# 小米白板 (Mi Paint)

**一個簡約、流暢且功能強大的網頁版繪圖白板**

---

**簡介**

此專案為一個基於 Web 技術開發的單一檔案繪圖應用程式，
提供使用者流暢的書寫體驗與無限的創意空間。
模擬真實筆觸，適合用於塗鴉、手寫筆記、教學演示或會議記錄。

使用者可以建立多個畫布，並自訂畫布尺寸與背景，
快速使用的繪圖功能包括：
* **多樣化筆刷**：鋼筆（壓力變化）、圓珠筆（等寬）、螢光筆（半透明疊加）。
* **繪圖模式**：支援自由曲線與幾何直線切換。
* **真實壓感**：支援 Redmi靈感觸控筆、Apple Pencil 或數位繪圖板的壓力感應。
* **索套工具**：可圈選物件進行移動、複製或批次刪除。
* **雷射筆**：軌跡會隨時間自動淡出，適合演示使用。
* **觸控筆按鈕操作**：特別針對Redmi靈感觸控筆提供按鈕操作的快速鍵功能。

**其他功能**
* 無限畫布 / A4 / A3 分頁模式
* 背景樣式切換（純白、米色、網格）
* 雙指縮放與平移畫布
* 防誤觸模式 (Palm Rejection)
* 橡皮擦 (一般擦除 / 整條擦除)
* 筆刷參數記憶 (本地儲存)
* 畫布自動存檔與縮圖預覽

## 使用方式

1. 請前往 [mi_paint](https://potatosserver.github.io/mi_paint/)即可使用白板。
2. 點擊右下角的 `+` 按鈕建立新畫布。
3. 點擊頂部工具列切換筆刷，再次點擊可開啟詳細設定（顏色、粗細、直線模式）。
4. 點擊右上角設定圖示可調整壓力感應模式與觸控筆快捷鍵。

## 技術來源與相依套件

本專案使用了以下開源技術：
- [Perfect-Freehand](https://github.com/steveruizok/perfect-freehand) - 筆跡路徑生成算法
- [Lucide](https://lucide.dev/) - 使用者介面圖標
- [Iro.js](https://iro.js.org/) - 顏色選擇器

## 已知問題

* 在極大量筆跡的畫布上，縮放操作可能會有些微延遲。
* 部分舊版移動瀏覽器可能不支援 `coalescedEvents`，導致快速畫線時線條不夠平滑。
